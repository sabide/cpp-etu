# TD/TP 4 — squelette étudiant

Le projet de départ contient la classe RAII de la séance 3. La copie reste
interdite avec `= delete` : le TD consiste à diagnostiquer la copie implicite,
puis à implémenter copie indépendante, affectation, déplacement et
`operator[]`.

```bash
make
make run
```

Les sanitizers restent actifs pendant tout le TD.
