# TD de synthèse — Du C++ moderne à un premier maillage 2D

Ce dossier contient le sujet du TD de synthèse et le code de départ.

Voir les fichiers :

- `td/enonce/td_synthese_gmsh.pdf`
- `td/enonce/code/` pour les sources étudiant
- `td/correction/td_synthese_gmsh_correction.pdf`
- `td/correction/code/` pour les corrections

Le code est compilé avec des options C++20 et les sanitizers (ASan/UBSan)
pour les parties C++ fournies dans les TD.
