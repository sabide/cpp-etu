# Code de départ — TD/TP 2

Le dossier contient les deux points de départ annoncés dans le sujet :

- `int_array_c.*` et `main_c.c` : version C à observer ;
- `int_array.*` et `main.cpp` : première version C++ à fonctions libres.

```bash
make
./build/int_array_c
./build/int_array_cpp
```

La cible C++ active les sanitizers pendant tout le TD. Conservez une copie de
la version à fonctions libres avant de transformer les opérations en fonctions
membres.
